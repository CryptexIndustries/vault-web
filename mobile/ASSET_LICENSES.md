The app is AGPL-3.0-only. The repository's [LICENSE.md](../LICENSE.md) contains the full license. Cryptex icons, splash images and brand marks in `mobile/assets/` are project artwork distributed with the app under that license.

| Expo Google Fonts loader | 2020 Expo, MIT | [expo-google-fonts-LICENSE.txt](fdroid/notices/expo-google-fonts-LICENSE.txt) |
| Lucide icons | Lucide Contributors; Feather-derived portions by Cole Bemis, ISC/MIT as stated by upstream | [lucide-LICENSE.txt](fdroid/notices/lucide-LICENSE.txt) |

These notices and the app's AGPL license are copied into the Android APK's `assets/licenses/` directory by the existing dependency-verification plugin. Font and icon notices are copied verbatim from the pinned npm packages. Native WebRTC attribution and the source-built OpenSSL 3.5.8 Apache-2.0 license are packaged there too. For native source builds and checks, see [F-Droid build notes](fdroid/README.md).

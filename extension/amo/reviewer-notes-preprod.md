To test device linking:

1. Open pp.cryptex-vault.com/app and choose Create. Enter a name and a secret key, then choose Create Vault. Tick the recovery code box and choose Continue.
2. In the sidebar choose Sign up, then Create account. Solve the captcha and choose Register & sign in. Save the Recovery Kit (copy or download it, then tick the box).
3. Open Account and choose Upgrade (Monthly). Pay with card 4242 4242 4242 4242, any future expiry date and any CVC and ZIP.
4. In the PRE-PROD extension choose Link this device. In the web app open Linked Devices, choose +, then Send link request and Start linking. In the extension scan the QR code (allow the camera) or paste the code copied from it. Keep both open until they are linked, then unlock with the same secret key.

Build steps are in BUILD-INSTRUCTIONS.md at the root of the source archive. The changes in each version are in extension/CHANGELOG.md.
